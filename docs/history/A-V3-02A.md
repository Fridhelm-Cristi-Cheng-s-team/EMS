# EMS V3 · A‑V3‑02A A 方独立系统接口与数据契约设计

> 根据历史对话整理，非逐字原文。原任务当时的技术建议与执行状态在下文保留。当前有效设计见 [V0.1 文档入口](../README.md)。

## 原报告状态及范围

初始候选交付为 PROPOSED，待 A 方审核。02A 范围为 I01–I10 与 I07Q；02B 留给能源内部；02C 留给 A/B 交接。六系统、串联及六状态工作假设继续采用。B 方数据只登记依赖；未制作替身。

## 原契约与设计选择

| 组 | 原接口及主要候选定义 |
|---|---|
| I01/I02 | 阶段、目标模式、空速、单垂向目标、约束、目标 ID 与转换事件；飞行状态/角度、目标跟踪、推进受限摘要 |
| I03/I04 | 当前任务上下文、剩余估计及预测；可选飞行状态、推力请求和受限影响。预测缺失可运行基础 EMS |
| I05/I06 | 推力请求、命令元数据、基准点运动和安装定义；机体系真实力、固定点俯仰矩、轴向跟踪、可用能力和诊断量 |
| I07Q/I07/I08 | 机体位置与求值时刻；S5 大气真值、总风与有效性；S4 同源密度与风、可选热环境和来源引用 |
| I09/I10 | 配置、逐系统初态、开始/停止；Ready、运行事件和源日志，S6 只管生命周期 |

原轮建议真空速加单垂向模式：爬升升降率转高度捕获，巡航空速和高度，下降任选地速垂向率或空气航迹角。S1 切换阶段；S2 可报告跟踪或不可持续。S4 从 I05 和 I08 唯一派生局部入流和正式电需求。I06 发布固定点 (O) 的力和矩，S2 换算 (M_{CG}=M_O+r_zF_x-r_xF_z)。环境真值、测量及估计分开。S6 只在必需系统 Ready 后启动。

公共规范使用 SI、具名 Bus、标量/向量、事件与时间标识，区分连续求值和离散采纳。原来采用 VALID、UNINITIALIZED、OUT_OF_DOMAIN、STALE、NUMERIC_INVALID。I06 当时的 `availableThrust` 是未充分分层的候选，随后被 02AR 明确替换。原候选阶段信息流随后改为先确认后提交。未被修订的基本信号继续有效于[当前系统接口](../interfaces/system_interfaces.md)。

## 决策与测试

A02A‑01–08 涉及目标组合、来流权属、参考点、过期回退、EMS 可选信息、测量/环境、实验 Ready 和 Bus/模型粒度。T01–T13 覆盖类型、单位、权属、阶段、目标冲突、快照、EMS 可选信息、坐标、请求/实际、受限恢复、环境、直接馈通、初态、重复性和终止，均 NOT RUN。D01 燃油、D02 实际发电、D03 发电能力、D04 发电状态、D05 发动机环境留给 02C；D06 能源内部留 02B；D07 A 方参数及保真度留模型阶段。

原轮未写入仓库或运行模型。后来 [02AR](A-V3-02AR.md) 对握手、失效回退及推进能力作增量修订。
