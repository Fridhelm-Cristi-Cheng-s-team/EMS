## 气动、动力学与环境

| P‑B 参数 | 候选值 |
|---|---:|
| $C_{L0}, C_{L\alpha}, C_{Lq}, C_{L\delta_e}$ | 0.28, 5.46485, 3.88278, 0.32967 |
| $C_{L\max}, C_{D0}, e$ | 1.50, 0.028, 0.82 |
| $C_{m0}, C_{m\alpha,r}, C_{mq}, C_{m\delta_e}$ | −0.040, −0.74408, −10.28937, −0.87363 |

使用 $\hat q=q\bar c/(2V_a)$；$C_L,C_{m,r}$ 对 $\alpha,\hat q,\delta_e$ 取相应线性关系；$C_D=C_{D0}+C_L^2/(\pi e AR)$。角变量内部用 rad，升降舵后缘向下为正。$C_{L\max}$ 用于单独失速速度估计，线性模型不提供失速后的力。03A 的短、长周期和灵敏度保留；本轮没有设计控制律。优先标定零升阻力、升力/力矩导数、舵效、CG/Iy 和失速附近性能。

六状态为 $[X,Z,u,w,\theta,q]^\mathsf T$。惯性 X 向前、Z 向上，机体 x 向前、z 向下，俯仰抬头为正。令 $R=[(\cos\theta,\sin\theta);(\sin\theta,-\cos\theta)]$：
- $(\dot X,\dot Z)=R(u,w)$；$(u_a,w_a)=(u,w)-R^\mathsf T\mathbf W$。
- $V_a=\|(u_a,w_a)\|$、$\alpha=\operatorname{atan2}(w_a,u_a)$、$\gamma_a=\theta-\alpha$，$\gamma_g$ 由对地速度给出。
- $L,D=\rho V_a^2 S(C_L,C_D)/2$，机体气动力分量为 $(L\sin\alpha-D\cos\alpha,-L\cos\alpha-D\sin\alpha)$。气动参考矩为 $\rho V_a^2 S\bar c C_{m,r}/2$，依实际气动力换算到重心。
- S4 发布真实推进力和固定点矩，S2 只按 $M_{CG}=M_O+r_z F_x-r_x F_z$ 换算一次。$\mathbf r$ 从 CG 指向 O。
- $\dot u=F_x/m-qw-g\sin\theta$，$\dot w=F_z/m+qu+g\cos\theta$，$\dot\theta=q$，$\dot q=M_y/I_y$。$F_x,F_z$ 为非重力合力。S2 负责唯一物理状态，S5 提供同源风与标准大气；实际舵面与推力请求分别追踪。

环境采用低层标准大气，$T_0=288.15$ K、$p_0=101325$ Pa、温度递减率 0.0065 K/m、$R=287.05287$ J/(kg·K)、$g=9.80665$ m/s²。本轮正常任务 300–1500 m；原研究网格 0–2500 m，其中 0 m 是密度对照。

## 有效域和可行性分层

1. **气动近似域**：03A 线性导数及抛物极曲线的申明工况，迎角 −5–11°、$|\hat q|\le0.04$，研究真空速 25–49 m/s。舵偏候选 ±20°，速率 45°/s 后续动态验收。
2. **失速估计**：$V_s=\sqrt{2mg/(\rho S C_{L\max})}$，依赖待标定 $\rho,C_{L\max}$ 条件。P‑B 名义巡航 20.76 m/s。
3. **研究筛选**：$V_a/V_s\ge1.30$、$C_L\le0.85C_{L\max}$，以及非负推力及舵面范围。依据为候选设计范围。
4. **纵向配平可行**：三力/矩残差在容差内并通过筛选。03A 的 1,384 样点仅通过此层，采样边界也不构成连续包线保证。
5. **推进能力**：由真实桨、电机及电气/热约束决定，分别考虑时域和持续时间。I06 的实际输出与能力仍分开。
6. **任务能源可行**：须同时满足持续供能、SOC 和备用、燃油/发电及网络平衡。300 km 是候选试验目标；36 kg 可用燃油无法单凭推进能耗证明足够。

## 接口与量纲修正

I01/I02 保持任务守卫及 S2 状态/持续性反馈；I05/I06 保持坐标与基准点；I07Q/I07/I08 保持 S5 同源；I09/I10 记录版本、替身、条件和误差。没有更改 ICD 或审批状态。

03A 的推力直接控制导数 $\partial\dot\gamma_a/\partial T$ 数值约 $3.27887\times 10^{-6}$，单位修正为 **rad/(s·N)**。$\partial\dot V_a/\partial T$ 使用 m/(s²·N)，$\partial\dot q/\partial T$ 使用 rad/(s²·N)。状态列和行导数的单位按 $\dot x_i/x_j$，角度在计算中用 rad。修订不改变数值或极点。

## 能源边界

$P_{\mathrm{eff}}=T\,V_a\cos(\alpha+\delta_T)$。03A 相容估算使用桨效率 0.68–0.82、共享轴机械损耗折算 0.97–0.99、电驱效率 0.88–0.95。折算仅计一次，代表未细分的机械损耗，并未引入减速器。05A/05B 使用桨轴实际功率及共享轴实测 $P_f=\tau_f\omega$ 时，移除该乘法折算。电驱效率对应入口至电机输出，不应再扣同一轴承、变换或已入电驱地图的损耗。若采用理想直接共享轴，令机械折算为 1。低载筛选 $P_{\mathrm{eff}}<2$ kW 时，CSV 留空效率折算列。该 03AR 筛选只控制估算报告。所有发电侧额定功率及能量分担保持待定。
