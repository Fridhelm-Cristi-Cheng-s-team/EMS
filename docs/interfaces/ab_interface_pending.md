01R 候选口径要求 B 方保留发电机负载反力矩及真实轴速。对所选控制边界，若其他路径均归账，可用 $P_{\rm shaft,in}-P_{AB}-P_{\rm loss,B}=\dot E_B$ 核对。A 方功率账在同一窗口使用相同的 $P_{AB}$，两侧合账时该项抵消。启动取电可为负；若采用独立启动端口，应保留独立计量并纳入总账。实际端口及归属待联合审议。

02C 前由 A 方准备需求工况、公共网络与启动候选、接纳条件、辅机优先级和能源对账测试。B 方提交物理架构、发电动态限制及接口提案。双方审查测量边界、联合初态、实际交换、时域、限载和验证证据。
