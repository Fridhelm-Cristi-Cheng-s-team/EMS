# 统一接口规范

**A-side Design Baseline V0.1 · REVIEWED / NOT FROZEN**

## 标识和边界

保留 I01–I20、I07Q 及其 Signal ID。新增项取同接口的未使用编号。移除项只出现在修订或历史记录。每行定义发布者、消费者、所有者、单位、维度、参考边界、符号、有效域、运行和初始化策略、回退、验证、依赖以及来源。表头规则与逐行定义共同构成契约。未批准的具体值记为 `TBD`。

采用 SI：m、kg、s、m/s、m/s²、rad、rad/s、N、N·m、W、J、K、Pa、kg/m³；电气 V、A、电荷 C，SOC 为 0–1。边界导入/显示层转换 °、kW、rpm 等。惯性系 X 向前、Z 向上，机体系前/右/腹，俯仰抬头为正。轴向来流使用相对空气速度沿推进轴前向的投影。电池向网络、B 向 A 为正、电驱取电为正。力矩及功率字段必须标明参考点或测量端。

连续实数候选为 double，布尔为 logical，模式和原因用枚举，异质记录可采用 Bus。ID 位宽、实际采样周期和求解器待定。向量注明维度和分量。一个真实状态或实际端口量只有一个权威来源。估计、预测、边界、命令、已采纳目标和实际值分别标注。

## 时序、有效性及恢复

| 类别 | 公共规则 |
|---|---|
| C 连续 | 同一物理求值点使用一致输入。共同求解时不为每个标量附消息时标。跨速率消费保留源时刻及有效保持依据 |
| P 周期 | 记录源时刻、快照序号和采纳时刻。控制请求另有生效及到期时刻，通常按半开区间采纳 |
| E 事件 | 携带发生时间、运行标识、关联版本和原因。按事务幂等处理。旧运行、过期或已关闭事务只记录 |
| I 初始化 | S6 提交配置和初值候选，各所有者校验并设置自己的状态。收齐本次必需 Ready 后启动 |
| L 日志 | 源模块记录真实量与来源，S6 汇集。保存源/采集时刻、接口与模型版本、替身标识、事件及退出证据 |

`VALID`、`UNINITIALIZED`、`MISSING`、`STALE`、`SOURCE_MISMATCH`、`OUT_OF_DOMAIN`、`NUMERIC_INVALID` 表示信息状态。必需物理输出不可用、正常限功率、请求不可行、恢复事件、空可行集或能力未知另行表述。能力的预测起点和覆盖时域与消息有效期各自记录。到期后的能力不得放宽既有限制。可选通道失效可停用，关键通道只有在存在经批准且有效的回退时继续。无效载荷或环境真值不能以默认零替代。

候选阶段事务携带运行、转换、目标和基准版本。S2 先评估候选，S1 在确定时序的共同生效点提交，S2 同点采纳。停止已生效时优先，未提交项关闭，提交后错配按协议异常记录。实验终止区分任务完成、运行边界、物理输入无效、数值或协议异常。保持最后有效及并发事件证据，日志不参与飞控或能源策略决策。

## 版本、审批与证据

不兼容的单位、符号、参考点、必需项、时序及所有权更新主版本。可忽略且兼容的增项可更新次版本。接收者验证版本。验收资料关联接口、场景、参数、工具版本和时标。跨系统变更在 docs/ 记录；跨 A/B 变更必须双方评审。定稿或冻结需要单独批准。
