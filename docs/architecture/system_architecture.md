# 总体系统架构

**A-side Design Baseline V0.1 · REVIEWED / NOT FROZEN**

## 研究范围

EMS V3 面向 500 kg 级固定翼混合动力飞机研究。500 kg 为当前最大起飞质量目标。首版研究空中爬升、巡航、下降，X–Z 纵向及俯仰运动，飞控、独立 EMS、混动动态和环境扰动。正常启动、停机、供能不足及耗尽纳入运行边界。地面滑跑、离地、接地、起落架、跑道、刹车和部件故障注入为 `OUT OF SCOPE`。主动再生、功率电子纹波及快速电气瞬态为后续保真度选项。原始参考资料供只读研究；软件及模型独立实现。

## 系统与所有权

| 系统 | 职责、状态和控制权限 | 主要边界 |
|---|---|---|
| S1 任务 | 唯一写入任务阶段，持有守卫、阶段计时和目标版本 | 向 S2 发送飞行目标，向 S3 发送已提交阶段及可选预测。S2 提供跟踪反馈 |
| S2 飞机与飞控 | 持有机体真实六状态、舵机与飞控模式/命令，计算机体受力、质量及可选估计 | 接收 S5 真值、S1 目标和 S4 载荷。向 S4 发送推力请求及机体运动 |
| S3 独立 EMS | 独占监督层能源调度和策略状态，输出发电调度意图与电池窗口 | 读取 S4 正式需求、实际功率和能力；S1/S2 上下文按策略选用 |
| S4 混动仿真 | 持有能源及推进实际状态和输出，联立功率平衡，执行硬限制，形成唯一电需求和能力 | A 方负责电池、公共网络、推进及集成。B 方负责发动机、库存、发电机、轴系、底层控制及独立台架 |
| S5 环境 | 唯一大气及风场来源，持有环境和扰动状态 | S2、S4 共用有时空引用的真值。测量适配由消费者负责 |
| S6 实验 | 持有配置、初始化就绪、实验开始、停止和日志 | 组织试验、采集与评价；运行期各系统持续拥有其物理状态和控制决策 |

## 拓扑及信息流

候选首版为**串联电推进**。发动机机械轴驱动发电机，净交换进入公共电气网络。电池双向补差，电驱通过推进轴和桨产生载荷。串联支持发动机负载动态、发电爬坡、SOC 调度和任务能量闭环。并联与功率分流可研究直驱、模式切换和机械分配，需增加传动参数及验证；保留为架构选择。设备型号、桨数和母线参数为 `TBD`。

- **飞行控制**通过活动目标、舵面执行、实际推进载荷和机体反馈闭合。S1 只在握手提交后更新阶段。
- **能源管理**通过 S4 唯一电需求、S3 调度、S4 实际执行和能源反馈闭合。实际功率与需求可单独追踪。
- **推进耦合**由实际电功率、转矩、共享轴速、桨载荷、飞机运动和来流闭合。
- **发动机发电耦合**要求 B 方在其边界内保留实际负载反力矩、共享轴响应和净发电。联合端口待 [A‑V3‑02C](../interfaces/ab_interface_pending.md)。
- **实验**按配置、逐系统校验、就绪、运行、终止、评价进行。日志为旁路。

物理状态连续求值，电驱与硬限制快速执行，飞控和 EMS 在各自采纳点使用一致快照，任务守卫由事件与反馈驱动。采样数值、计算预算及求解器为 `TBD`。共同物理联立由状态/方程处理。Simulink 候选以 S2、S3、S4 为可独立测试边界，按成熟度选择 Subsystem 或 Model Reference。
