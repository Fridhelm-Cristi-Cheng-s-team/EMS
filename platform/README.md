# Platform

This module covers the aircraft physics simulation platform, flight control, EMS, and overall system integration. Platform implementation and integration work is developed separately from the engine model. A方 reviews integration changes.

Record cross-module interface changes in `docs/` and obtain review from both sides before merging them.


飞机物理参数候选基线及可复现计算证据归档于 [`parameters/aircraft/v0.1/`](parameters/aircraft/v0.1/README.md)，参数仍为 `PROPOSED / NOT FROZEN`，该归档不冻结 A/B 联合接口。
